# Before/After 실측 — 과제 2

과제 1 측정은 [`task1/02-measurement.md`](task1/02-measurement.md)에 있다.

## 측정 방법

- **Before = 스위치를 모두 끈 LLM 단독, After = 기본값.** 같은 커밋, 같은 평가셋에서 스위치만 바꾼다
  ([결정 0009](decisions/0009-rating-domain.md)).

  ```bash
  ROUTER=llm RATING_CLARIFY=off CASE_SEARCH=off RATING_ASSESSOR=direct VALIDATOR=format \
    MEASURE_QUERIES=tools/queries_rating.json scripts/measure-at <커밋> before rate,rroute,rclarify,rjudge,e2e
  MEASURE_QUERIES=tools/queries_rating.json scripts/measure-at <커밋> after rate,rroute,rclarify,rjudge,e2e
  ```

- 백엔드는 ollama — qwen3:0.6b(분류·대화), qwen3:8b(판정·작성·검수), qwen3-embedding:0.6b(사례 검색·라우터).
- 평가셋은 [`tools/evalsets/`](../tools/evalsets/)의 `rating*.json`, 회귀 쿼리는 [`tools/queries_rating.json`](../tools/queries_rating.json).

## 측정한 커밋

Before·After 는 늘 **같은 커밋에서 스위치만 바꿔** 쟀다. 커밋이 여럿인 것은 측정 뒤에 고친 것이 있어서다.
뒤 커밋에서 다시 재지 않은 지표는 그 사이 변경이 해당 경로를 건드리지 않았다(아래 "다시 재지 않은 이유").

| 커밋 | 무엇 | 잰 것 |
| --- | --- | --- |
| `b0cb295` | 뼈대(LLM 단독만) | `before0` — 측정 경로 점검용 1차. 비교에는 쓰지 않는다(아래 `0876038` Before 와 수치가 같다) |
| `0876038` | 기능 1~6 | 평가셋 A · 분류 · 되묻기 · 검수 · 회귀 쿼리 — Before / After / 사례 검색 끔 |

- 무작위로 고르면 기대 정확도는 10/40(등급마다 10개씩이라 최빈 등급도 10/40)이다. **사례만 보는 기준선이 에이전트보다 높다** — 아래 기준선 절.
- **정확도를 올린 것은 사례 검색이다.** 사례 검색을 끄면(기준표 판정만) 8/40으로 Before 보다도 낮다. 한 문장 개요에는 등급을 가른 표현이
  거의 없어, "설명에 없는 표현은 짐작하지 않는다"는 판정이 거의 모든 항목을 비우고 낮게 본다. 5개는 "무엇을 하는 게임인지 알 수 없다"며 되물었다.
- 40문항에서 4문항 차이(14 → 18)는 우연과 구별하기 어렵다. 차이가 분명한 것은 청소년이용불가(1 → 5)와 내용정보 정밀도(0.16 → 0.82)다.
  LLM 단독은 등급과 상관없이 내용정보를 거의 다 붙였다.
- 과소평가가 여전히 21건이다 — 가장 위험한 방향(출시 뒤 등급 상향)의 오류가 남아 있다.
