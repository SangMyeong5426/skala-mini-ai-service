# 0007: 대화(chat) 경로만 thinking 유지 — 항목 1 보완

- 상태: Accepted
- 날짜: 2026-10-20
- 보완 대상: [0002](0002-ollama-think-control.md)

## 문제

항목 1(`OLLAMA_THINK=false`)은 fast·quality 모델의 모든 호출에서 생각을 끈다. 장애 처리 경로는 크게
빨라졌지만, 대화 경로(`chat`, qwen3:0.6b)의 답이 어색해졌다. final 회귀 쿼리에서 "제 이름은 민수입니다"와
"제 이름이 뭐였죠?" 둘 다에 "민수님의 이름이 정확히 알려졌습니다."라고 답했다. 대화는 원래 1~2초짜리
경로라 생각을 꺼서 얻는 시간 이득이 작다.

## 결정

**대화 경로만 따로 정한다.** `OllamaFastLLM`에 `chat_think`를 두고 `chat()`만 그 값을 쓴다. 분류·계획·
보고서 작성·검수는 지금처럼 `OLLAMA_THINK`를 따른다.

| 환경변수 | 값 | 지정하지 않으면 |
| --- | --- | --- |
| `OLLAMA_THINK_CHAT` | `true` · `false` · `default` | `OLLAMA_THINK`가 `default`(원본)면 `default`, 그 밖에는 `true` |

원본을 재현하는 조합(`OLLAMA_THINK=default`)에서는 대화도 원본 그대로가 되도록 기본값을 `OLLAMA_THINK`에
묶었다. 코드는 `_payload()`·`_chat_stream()`이 think 값을 인자로 받게 바꿔, 부르는 쪽(chat·write)이 정한다.

## Before/After

회귀 쿼리를 같은 조건으로 다시 쟀다(`runs/e2e_final2_20261020-132116.json`, 코드 `32b59c1`).

| 대화 질문 | base | final (생각 끔) | final2 (대화만 생각) |
| --- | --- | --- | --- |
| 안녕, 너는 누구야? | 1.9초 | 0.4초 · "안녕하세요! 저는 '비서'입니다. 😊" | 0.9초 · "안녕하세요! 저는 빠르게 비서입니다." |
| 제 이름은 민수입니다 | 1.9초 | 0.3초 · "민수님의 이름이 정확히 알려졌습니다." | 0.5초 · "안녕하세요!" |
| 제 이름이 뭐였죠? | 1.2초 | 0.2초 · "민수님의 이름이 정확히 알려졌습니다." | 0.6초 · "저의 이름은 민수입니다." |

회귀 쿼리 한 번으로는 판단하기 어려워, 같은 모델에 대화 6가지를 생각 끔·켬으로 넣어 비교했다(temperature 0).

| 상황 | 생각 끔 | 생각 켬 |
| --- | --- | --- |
| 이름 기억 — 이전 답이 짧음 | ✗ "민수님의 이름은 뭐였죠?" | △ "저의 이름은 민수입니다." |
| 이름 기억 — 이전 답에 이름 | ✗ "민수님의 이름은 뭐였죠?" | ✓ "민수님!" |
| 이름 기억 — 다른 이름(지수) | △ "내 이름은 지수입니다! 🌟" | ✗ "안녕하세요! 이름을 알려주세요!" |
| 이름 소개 | ✗ "민수님의 이름이 정확히 알려졌습니다." | ✓ "안녕하세요!" |
| 개념 질문 (ai 에이전트) | ✓ | ✓ |
| 감사 | △ "감사합니다! 감사합니다. 😊" | ✓ "감사합니다! 해결했으면 좋겠습니다. 😊" |
| 지연 (6건 평균) | 0.21초 | 0.68초 |

**자연스러운 답이 6건 중 1 → 4로 늘고 지연은 약 0.5초 늘었다.** 대화 품질을 원래 수준으로 되돌린 것이다.
장애 처리 경로는 바뀌지 않는다.

## 한계와 트레이드오프

- **0.6b의 기억력 한계는 그대로다.** 이름 기억 3건 중 정답은 1건(생각 끔은 0건)이고, "다른 이름" 상황은 오히려
  틀렸다. base도 같은 모델·같은 설정이라 같은 한계를 가졌다. 더 고치려면 대화 이력에서 이름을 코드로 뽑아
  프롬프트에 사실로 넣거나(fake 백엔드가 쓰는 방식), 대화를 큰 모델로 돌려야 한다 —
  [`followups.md`](../followups.md).
- 대화 6건 비교는 사람(작성자)이 판정했다. 표본이 작다.
- 스위치가 하나 늘었다. `OLLAMA_THINK_CHAT`의 기본값이 `OLLAMA_THINK`에 따라 달라지므로, 실제 값은
  `/health`의 `switches`로 확인한다.
