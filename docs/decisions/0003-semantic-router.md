# 0003: 질문 분류를 임베딩 기반 의미 라우터로

- 상태: Accepted
- 날짜: 2026-10-20
- 계획 항목: [`01-plan.md`](../task1/01-plan.md) 순번 2 · 설계 [`03-design.md`](../task1/03-design.md#항목-2--임베딩-기반-의미-라우터)

## 문제

`route_node`는 fast 모델(qwen3:0.6b)에게 chat/incident를 묻는다. 개념·기술 설명 요청을 장애로 보내는
오분류가 반복됐다 — 웹에서 "ai 에이전트에 대해 설명해줘"가 auth-service 진단으로 끝났다. 평가 세트
30문항에서 base 23/30(일반 질문 15개 중 6개 오분류), thinking을 끈 step1 24/30.

## 검토한 선택지

### A. 프롬프트 보강 — 분류 지시문에 예시를 더 넣는다

가장 싸다. 하지만 0.6b 모델이 지시를 얼마나 따르는지가 그대로 변수로 남고, 호출마다 1초 안팎이 든다.

### B. 더 큰 모델로 분류 — quality(8b)에게 묻는다

정확도는 오를 수 있지만 모든 질문에 8b 호출이 붙는다. 분류 한 번에 수 초가 든다.

### C. 예시 문장 임베딩 + kNN, 애매할 때만 LLM

분류 예시 40문장(클래스당 20)을 기동 때 임베딩해 두고, 질문과의 유사도로 판정한다. 두 클래스 점수 차가
작을 때만 기존 LLM 분류로 넘긴다. 질문 하나의 임베딩은 0.04초다.

## 결정

**C를 택한다.** 점수 = 클래스별로 가장 가까운 예시 3개의 코사인 유사도 평균, 차이 = incident − chat.
|차이| ≥ margin이면 그 클래스, 아니면 LLM 폴백.

| 파일 | 변경 |
| --- | --- |
| `agent/embedding.py` | `OllamaEmbedder`(qwen3-embedding:0.6b), `cosine` — 항목 3·5와 나눠 쓴다 |
| `agent/router.py` | `SemanticRouter`, `LLMRouter`(base 래퍼, 폴백 대상) |
| `data/router_examples.json` | 클래스당 20문장. 평가 세트와 겹치지 않게 썼고 테스트가 겹침을 검사한다 |
| `server.py` · `agent/deps.py` · `agent/graph.py` | `ROUTER` 스위치로 조립, `route_node`가 라우터를 쓰고 이벤트에 `method`·`gap`을 남긴다 |

**판정 기준은 평가 세트로 고르지 않았다.** `tools/tune_embedding.py`로 예시 문장 안에서 leave-one-out을 했다
(예시 하나를 빼고 나머지로 그 예시를 분류).

| 조건 | LOO 정답률 | 틀린 예시 | 차이 중앙값 |
| --- | --- | --- | --- |
| Qwen3 지시문 붙임 | 0.925 | 3 | 0.075 |
| **지시문 없음** | **0.95** | 2 | 0.122 |

지시문 없이를 택하고, margin은 LOO에서 틀린 예시의 |차이| 최댓값(0.024)보다 조금 큰 **0.029**로 정했다.
예시 문장 기준으로 10%를 LLM에 넘기고, 직접 판정한 90%는 모두 맞았다
(`runs/tune-embedding_20261020-113108.json`).

## 한계와 트레이드오프

- **예시가 다루지 않는 표현에 약하다.** 평가 세트 30문항은 예시와 같은 범주(개념 설명, 인사, 증상 신고)
  안에 있다. 전혀 다른 범주(예: 배포 일정 문의)는 확인하지 않았다. 예시를 늘리면 관리할 문장이 늘어난다.
- **평가 세트와 예시를 같은 사람이 썼다.** 문장과 주제는 겹치지 않게 했지만(테스트로 확인), 범주를 정한
  사람이 같다는 편향은 남는다. 새 사람이 쓴 질문으로 다시 재면 더 공정하다.
- **margin은 예시 40문장으로 정했다.** 표본이 작아 margin이 조금만 달라도 LLM 폴백 비율이 크게 바뀐다.
  margin을 넓히면 0.6b 분류가 다시 많이 쓰여 오분류가 돌아온다.
- **임베딩 모델이 메모리를 더 쓴다.** qwen3-embedding:0.6b가 GPU 메모리 2.4GB를 차지한다(16GB 기기에서
  8b·0.6b와 동시 상주). 메모리가 모자라면 모델을 내렸다 올리며 1.4초 안팎이 더 든다.
- 임베딩은 ollama에 의존한다. fake·openai 백엔드의 기본값은 `ROUTER=llm`이다.
