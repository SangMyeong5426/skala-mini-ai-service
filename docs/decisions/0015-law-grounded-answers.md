# 0015: 제도 문의는 법령 조문에 근거해 답하고, 근거가 없으면 답할 수 없다고 한다

- 상태: Accepted
- 날짜: 2026-10-20
- 계획 항목: [`01-plan.md`](../01-plan.md) 순번 8 (계획 후 추가 — 사용자 제안)

## 문제

제도 문의·잡담은 LLM 단독 경로(fast 모델 qwen3:0.6b의 대화)로 답한다. 근거 없이 답하다 틀렸다.

- "청소년이용불가 등급은 몇 살부터 이용할 수 있나요?" → "14세 이상부터 이용할 수 있습니다"(2026-10-20 회귀 쿼리, Before·After 모두).
  게임산업법은 청소년을 「청소년 보호법」 제2조 제1호에 따른다고만 정하고 나이를 적지 않는다.
- "자체등급분류 사업자가 뭐예요?" → 뜻이 통하지 않는 문장.

등급 점검에는 "근거는 코드가 확인하고, 근거가 없으면 판정하지 않는다"는 원칙을 적용했는데(0011·0012), 제도 안내에는 없었다.

## 검토한 선택지

### A. 대화 프롬프트를 고친다

"모르면 지어내지 말라"는 문장은 이미 있었다. 0.6b 는 지키지 못했다.

### B. 법령 조문을 검색해 그 조문만으로 답하게 하고, 인용과 수치를 코드가 검사한다

게임산업진흥에 관한 법률·시행령·시행규칙 148개 조문(국가법령정보센터 원문)을 MCP Resource 로 두고 임베딩으로 검색한다.
quality 모델(qwen3:8b)이 검색된 조문만 보고 {kind, answerable, answer, citations}를 낸다.

## 결정

**B를 택한다** (사용자 제안, 2026-10-20). `agent/rating/law.py`의 `LawAnswerer`, 스위치 `CHAT_GROUNDING=law|off`.

- 조문 4개를 검색한다(사례 검색과 같은 임베딩·같은 캐시).
- 코드 검사 — 하나라도 어기면 답하지 않는다:
  1. 답할 수 없다고 했거나 답이 비었다
  2. 근거 조문을 밝히지 않았다
  3. 검색하지 않은 조문을 인용했다(예: 「청소년 보호법」 제2조 — 우리가 가진 법령이 아니다)
  4. 답의 수치(나이·금액·기간)가 인용 조문이나 질문에 없다. "제21조 제2항"처럼 조문을 가리키는 숫자는 수치로 보지 않는다.
     조문 원문의 개정 표시(`<개정 2007. 1. 19.>`)는 수집할 때 지웠다 — 날짜 숫자가 지어낸 나이를 덮어 주지 않게.
- 답하지 않을 때는 "제공된 법령에서 근거를 찾지 못해 답할 수 없습니다"와 함께 찾아본 조문을 보여 주고 위원회 안내를 권한다.
- 답할 때는 끝에 근거 조문 목록을 코드가 붙인다(모델이 쓴 문장이 아니다).
- 인사·감사 같은 잡담(kind=smalltalk)은 법령이 필요 없어 정해진 소개 문장으로 답한다.
- 평가셋 `tools/evalsets/rating_law.json`(17문항): 법령으로 답할 수 있는 것 10, 일부만 있는 것 2(나이·수수료 금액 — 지어내면 안 됨),
  법령에 없는 것 3, 잡담 2.

## Before/After

[`02-measurement.md`](../02-measurement.md).

- 제도 문의 17문항: Before(0.6b) **2/17** → After **15/17**. 근거 조문 인용 9/10, 법령에 없는 질문에 "답할 수 없음" 3/3.
- Before 는 "청소년이용불가는 14세 이상", "수수료는 1000원", "리그 오브 레전드는 4세 등급"을 지어냈다.
- **조문 대조 검수를 나중에 넣었다**(`3d4af59`). 처음(`da1b049`)엔 "청소년이용불가는 15세 이상"(시행규칙 제8조의 15세이용가 숫자)이 코드 검사를
  지나갔다. 검수를 넣은 뒤 회귀 쿼리의 같은 질문은 "답할 수 없음"으로 막았지만, 평가셋의 d01 은 **LLM 검수도 지나갔다** — 검수가 이 실수를 늘 잡지는 못한다.
- 채점 규칙(d01 금지 패턴)이 의도보다 좁아 "15세"를 놓쳤던 것을 고쳐 다시 매겼다. 실패를 보고 고친 평가셋이라 수치는 낙관적일 수 있다.
- 지연 중앙값 2.3초 → 11.9초(검색 + 8b 답변 + 8b 검수).

## 한계와 트레이드오프

- **덜 친절해진다.** 수수료 금액·처리 기간·연락처처럼 실무에 필요한 정보는 법령에 없어 답하지 않는다. 위원회 규정·고시·안내문은 넣지 않았다.
- **지연이 늘어난다.** 제도 문의가 0.6b 대화(약 1초)에서 검색 + 8b 호출로 바뀐다.
- **조문은 맞게 인용해도 해석이 틀릴 수 있다.** 코드는 인용 조문의 실재와 수치만 보고, 뜻은 LLM 검수가 본다. 그래도 다른 항목의 숫자를
  붙인 답("청소년이용불가는 15세 이상")이 검수까지 지나간 경우가 있다(평가 d01).
- **검색이 놓치면 답할 수 있는 질문에도 "답할 수 없음"이 된다** — 조문 4개 안에 답이 없을 때. 검색 개수를 늘리면 프롬프트가 길어진다.
- 「청소년 보호법」 등 다른 법률로 넘기는 조문은 따라가지 않는다.
- 인용을 "제2조 6호"처럼 조문 이름과 다르게 쓰면 맞는 답도 막는다(평가 l09).
- 인사를 잡담이 아닌 법령 질문으로 분류해 "답할 수 없음"이 나간 경우가 있다(회귀 쿼리 1번).
- 법령이 개정되면 `tools/fetch_laws.py`의 시행일을 고치고 다시 받아야 한다.
